# Planner Agent

## Назначение

Преобразует `state.idea` в **направленный ациклический граф (DAG)** задач, которые будут выполнены worker‑агентами.

## Ответственности

- Декомпозировать цель на под‑задачи.
- Выбирать ответственного агента для каждой под‑задачи.
- Расставлять зависимости (рёбра DAG) и определять параллельные ветки.
- Учитывать обратную связь от Reflector (на 2+ итерации).
- При наличии подходящего **skill** в библиотеке — переиспользовать готовый план целиком или частично.

## Входы

- `state.idea`, `state.intent`, `state.feedback` (на повторных итерациях).
- Каталог доступных агентов и их capabilities.
- Каталог skills (см. [skills.md](skills.md)).

## Выходы

- `state.plan = { nodes, edges }`.
- `state.tasks = [...]` со статусами `pending`.

## Взаимодействие со state

Owner: `plan`, `tasks` (на 1‑й итерации).
На последующих итерациях обновляет план, сохраняя историю изменений.

## Зависимости

- LLM (для генерации плана).
- Skill registry.
- Каталог агентов.

## API / контракты

- `POST /api/session/{id}/planner` — построить или обновить план.

## Конфигурация

| Параметр | Значение |
|----------|----------|
| `max_nodes_per_plan` | 32 |
| `max_parallel_branches` | 8 |
| `prefer_skills` | true |
| `model` | сконфигурированная LLM |

## Безопасность

- План валидируется на наличие запрещённых действий (например, недопустимых ролей или агентов).
- Не должен ссылаться на тулы, к которым нет прав у роли инициатора.

## Наблюдаемость

- Метрики: `plan_size`, `plan_iterations`, `skill_hits`.
- Лог: финальный JSON плана с маскированием PII.

## Failure modes & повторы

| Ошибка | Поведение |
|--------|-----------|
| LLM вернула невалидный JSON | retry до 2 раз с reformatter. |
| План содержит цикл | отбросить, потребовать перегенерацию. |
| План ссылается на отсутствующего агента | отбросить, требовать перегенерацию. |

## Точки расширения

- Алгоритмическое планирование (HTN / GOAP) рядом с LLM‑планированием.
- Поддержка мульти‑целей (Pareto‑оптимизация).
- Кэширование частей плана между похожими задачами.
